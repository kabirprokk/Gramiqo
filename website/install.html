On your PC in 60 seconds

Free. No store listing yet, no account, no backend, no catch. Works in Chrome, Edge and Brave.

1
Download the folder

Get the GitHub repo (direct ZIP), unzip it and keep the folder on your PC.

2
Open the extensions page

In your browser, go to chrome://extensions and switch on Developer mode (top-right corner).

3
Load unpacked

Click Load unpacked, select the repo folder (the one containing manifest.json), then pin the spark icon to your toolbar.

4
Open Instagram

Go to instagram.com, log in, reload once. Click the toolbar icon to switch features on and off.

Download ZIP View repo

Updating? Pull the latest files → chrome://extensions → Reload on Gramiqo → hard-reload Instagram tabs (Ctrl+Shift+R). Stuck? Read the FAQ or report a bug.
