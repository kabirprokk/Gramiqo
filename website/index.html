How to download & install

Free. 60 seconds. No store needed (we'll publish later).

1
Download the folder

Get the GitHub repo (direct ZIP), unzip it, keep the folder on your PC.

2
Open extensions page

Chrome / Edge / Brave → chrome://extensions → enable Developer mode (top-right).

3
Load unpacked

Click Load unpacked → select the inta-enhancer folder → pin the spark icon to toolbar.

4
Open Instagram

Go to instagram.com, log in, reload once. Click the toolbar icon to toggle features.

Download ZIP View repo

Updating? Pull latest → chrome://extensions → Reload on Inta-Enhancer → reload Instagram tabs.
