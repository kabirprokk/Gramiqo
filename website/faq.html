Yes — safe by design. No backend, no analytics, no password handling. It uses your existing Instagram cookies in your own browser (the same ones the site itself uses). Settings live only in Chrome storage.

Some reels are DRM/streaming-protected — the extension tells you instead of failing silently. Otherwise it queues via Chrome downloads; right-click → Save is the fallback. Audio is split straight out of the video file on-device, so it saves in milliseconds with zero quality loss.
